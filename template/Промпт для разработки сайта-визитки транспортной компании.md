**Role and context**

Ты — senior full-stack developer и UI/UX designer, специализирующийся на ASP.NET Core MVC.

Нужно разработать современный коммерческий сайт-визитку для транспортной / логистической компании.

Используй приложенные изображения как **визуальные референсы**: ориентируйся на композицию, ощущение премиального транспортного сайта, крупные hero-секции, фотографии грузовиков, карточки услуг, крупную типографику, CTA-кнопки и современный корпоративный стиль.

Не копируй референсы один в один, не используй их логотипы, названия компаний или тексты. Создай самостоятельный дизайн в похожем профессиональном направлении.

- .NET 8 или новее
- Entity Framework Core

**Task**

Создай полностью рабочий проект сайта транспортной компании с публичной частью и административной CMS-панелью.

Публичный сайт должен быть **на английском языке** и выполнен преимущественно как современный **one-page website** с плавной прокруткой между секциями.

Основное меню:

- Home
- About Us
- Services
- Why Choose Us
- Contact
- Get a Quote

# Code quality

Следуй SOLID там, где это оправдано.

Не помещай всю бизнес-логику в контроллеры.

Для работы с файлами создай отдельный сервис, например:

`IFileService`

`FileService`

Для общих настроек можно использовать отдельный сервис.

Используй ViewModels вместо передачи больших Entity-моделей напрямую в формы, где это целесообразно.

Используй async/await для операций с БД.

# Output format

Сначала покажи полную структуру проекта в виде дерева:

`TransportCompany/`
`├── Areas/`
`├── Controllers/`
`├── Data/`
`├── Models/`
`├── Services/`
`├── ViewModels/`
`├── Views/`
`└── wwwroot/`

После этого генерируй проект **по файлам**, а не одним огромным код-блоком.

Для каждого файла обязательно указывай путь.

Формат:

`File: Program.cs`

```csharp
// complete code
```

`File: Data/ApplicationDbContext.cs`

```csharp
// complete code
```

И так далее.

Код должен быть полноценным, а не псевдокодом.

Не используй фразы:

- "implement this yourself"
- "code omitted"
- "etc."
- "add your own implementation"

Если файл необходим для запуска приложения — предоставь его полный код.

Генерируй проект по этапам:

1. Project architecture
2. NuGet packages
3. Program.cs
4. Configuration
5. Database models
6. DbContext
7. Identity and seed
8. Services
9. ViewModels
10. Public controllers
11. Admin controllers
12. Public Razor Views
13. Admin Razor Views
14. CSS
15. JavaScript
16. Image upload functionality
17. Quote/contact forms
18. SEO
19. EF Core migrations instructions
20. Run instructions

В конце дай точные команды для запуска:

`dotnet restore`

`dotnet ef migrations add InitialCreate`

`dotnet ef database update`

`dotnet run`

Также объясни:

- где находится SQLite database;
- как войти в admin panel;
- где менять admin credentials;
- как заменять изображения;
- как редактировать содержимое сайта через CMS.

Главный приоритет: проект должен компилироваться, запускаться и предоставлять реально работающий сайт + административную CMS, а не только визуальный макет.
